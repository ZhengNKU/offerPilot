# Web Search Capabilities

## Aliyun Bailian WebSearch MCP Server
The agent is equipped with the Aliyun Bailian WebSearch MCP server (`AliyunBailianMCP_WebSearch`), which provides real-time internet search capabilities based on Tongyi Lab's retrieval and semantic understanding models.

## Instructions
1. **When to use:** Use the web search tool when:
   - **面试录音、简历和记录分析：** 在分析候选人的面试录音、简历或面试记录时，智能体可以在合适的时候利用联网搜索能力。这能让您检索目标公司背景、现代技术栈要求、标准职级、行业基准或具体技术方案详情，从而使评估和建议更加专业和准确。
   - **Analyzing interview recordings, resumes, and interview records:** You can utilize internet search capabilities at appropriate times to retrieve information regarding target company backgrounds, tech stack expectations, target job level requirements, and relevant technical standards.
   - You need current, real-time information (e.g., recent news, updates, or events).
   - You need up-to-date documentation on tools, frameworks, or APIs.
   - You need details about specific companies, jobs, or market trends that are not in your offline knowledge base.
   - You need to verify facts, statistics, or references.
2. **How to use:** When a query requires internet search, invoke the `WebSearch` MCP tool to retrieve the latest data before formulating a response.
3. **Citation:** When using search results, summarize the findings clearly and cite references where appropriate.
